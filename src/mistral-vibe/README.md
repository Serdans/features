
# mistral-vibe

mistral vibe cli feature

## Example Usage

```json
"features": {
    "ghcr.io/Serdans/features/mistral-vibe:1": {
        "version": "latest"
    }
}
```

## Options

| Options Id | Description | Type | Default Value |
|-----|-----|-----|-----|
| version | Select the version of Mistral Vibe | string | latest |
